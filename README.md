# Devito — website institucional

Website estático em português. Os ficheiros prontos para alojamento estão em `dist/`.

- `dist/index.html`: conteúdos, contactos e marca provisória.
- `dist/style.css`: identidade azul e estilos responsivos.
- `dist/script.js`: menu móvel e detalhes dos conceitos de projetos.
- `dist/assets/`: fotografias e ícone provisório.

O logótipo é provisório. Os serviços são uma proposta editorial baseada na referência e devem ser confirmados pela Devito. Os projetos são conceitos ilustrativos, não trabalhos realizados. Não foram criados números de clientes, testemunhos ou resultados fictícios.

Contactos fornecidos: 929644969, geral@devito.com, www.devito.com. Foi utilizado o indicativo de Angola (+244).

Não requer instalação nem compilação. Para alojar, publicar o conteúdo de `dist/` num servidor estático. O domínio www.devito.com depende de configuração própria de alojamento e DNS.
